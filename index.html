这是一个由创作者本人开发并仅供本人使用的桌面小工具。它读取我存放在本地硬盘上的视频母版文件， 通过 YouTube 官方接口（YouTube Data API v3）上传到我自己的 YouTube 频道 @jochemsin704，并自动填写标题、简介、封面与发布时间。 所有内容均为我本人原创、我本人版权所有。

YouTube 品牌元素

本工具在我的电脑上运行，界面与文档中出现的 YouTube 名称、红色播放按钮标识，均用于说明本工具与 YouTube 平台及 YouTube API 服务的集成关系。

Google OAuth 2.0

授权采用 Google 官方 OAuth 2.0「桌面应用」流程，仅申请 youtube.upload（上传）与 youtube.readonly（读取自己频道列表、避免重复上传）两项权限。

这个工具做什么

  • 读取本地母版：扫描我本机移动硬盘上的视频文件夹（我自己的原始成片，1080p / H.264）。
  • 与我的 B 站稿件配对：按上传日期 + 视频时长做交叉比对，确认「这条本地文件 = 我 B 站的那条稿件」，避免传错视频。
  • 上传到我的 YouTube 频道：调用 videos.insert 上传视频并设置标题、简介、标签与封面（thumbnail）。
  • 记录上传账本：本地保存一条台账，记录哪条视频已上传、对应的 YouTube 视频编号，防止重复上传。
  • 定时发布：回填历史视频时使用 YouTube 的定时发布（publishAt）能力，按我设定的时间逐个公开，避免集中刷屏。

工具性质：单用户、本机运行、无服务器、无对外服务。除我本人外，没有任何其他用户使用本工具，也没有任何其他用户的数据被处理。

为什么需要 API 配额

我的频道是一个个人创作频道，主要发布旅行、职场与生活类原创视频，平均每月更新 2–3 条。 目前我正在把过去几年在 B 站发布的历史视频逐步回填到 YouTube，预计涉及 30–60 条。 上传接口 videos.insert 默认配额下每天可上传 100 条，按我的发布节奏每天只需 1–3 次调用， 远低于默认上限；申请审计的目的是为了让通过 API 上传的视频能够以「公开」而非「私享」状态发布。
